# bpe-core

一个高性能流数据处理引擎，实现基于SQL的实时数据处理查询系统，具有JIT编译功能。

## 概述

bpe-core库是一个流数据处理引擎，设计用于处理连续数据流，支持SQL定义的数据转换和聚合。它通过LLVM基于JIT编译提供实时处理能力。

## 架构

### 核心组件

1. **核心系统 (`core.rs`)**: 主入口点，包含协调所有子系统的初始化函数
2. **数据管理 (`data.rs`)**: 模式定义和数据记录处理
3. **存储系统 (`store.rs`)**: 环形缓冲区实现以实现高效内存使用
4. **SQL处理 (`sql/`)**: SQL解析和执行管道
5. **JIT编译 (`jit/`)**: 基于LLVM的运行时代码生成
6. **处理组件 (`mapper.rs`, `aggregate.rs`)**: 数据转换和聚合逻辑

### 数据模型

- **U8Bytes**: 带有ID和大小元数据的二进制数据容器
- **Column**: 模式定义，包含名称、类型(Long/Double)和内存偏移量
- **Record**: 数据模式，包含命名列和类型信息
- **WrappedArray**: 流数据的环形缓冲区存储

### 处理管道

1. **数据注入**: 传入数据存储在环形缓冲区中
2. **SQL解析**: SQL语句解析为表达式树
3. **JIT编译**: 过滤器和表达式编译为原生代码
4. **执行**: 处理后的数据触发用户定义的回调

## 主要特性

### 性能优化
- 基于LLVM的JIT编译用于过滤表达式
- 内存高效的环形缓冲区存储
- 固定大小分配以最小化分配开销
- 直接内存访问模式以获得最佳性能

### SQL支持
- 带有过滤功能的SELECT语句
- 聚合函数(sum, count, avg, min, max, first, last)
- 通过下划线前缀函数名支持自定义函数
- 基于列的数据访问模式

### 可扩展性
- 自定义处理逻辑的回调系统
- 与其他系统的FFI支持
- 自定义函数的插件架构
- 具有Long/Double类型的类型安全数据处理

## 设计模式

### 全局状态管理
系统使用`globalvar`包在组件间共享状态，实现对配置、存储和处理组件的高效访问。

### 内存管理
- 原始指针操作以实现高性能数据访问
- 固定大小分配以防止碎片化
- 仔细边界检查的不安全代码块

### 处理模型
- 具有连续数据流的流式处理
- 用于处理结果的事件驱动回调
- 可配置的缓冲区大小和处理参数

## 安全考虑

- 广泛使用不安全代码需要仔细验证
- JIT编译在处理不受信任的输入时可能存在安全风险
- 对数据记录实现输入验证
- 内存边界检查对于安全操作至关重要

## 性能特征

- 通过JIT编译实现低延迟处理
- 环形缓冲区的内存高效存储
- 固定大小数据约束(512字节最大值)
- 针对高吞吐量流场景优化

## 配置选项

该库通过环境变量和TOML配置文件支持多种配置选项：

### 环境变量
- `BPE_HOME`: 配置文件的基目录(默认: 当前目录)

### 配置文件
- 配置文件路径: `cfg/config.toml`
- 支持的配置键:
  - `dev_mode`: 开发模式标志(布尔值)
  - `vec_size`: 内部向量的大小(默认: 1048576 字节)
  - `record_size`: 单个记录的大小(默认: 512 字节, 最大可配置: 512 字节)
  - `log_dir`: 日志文件目录

### 默认值
- `U8_DATA_MAX_SIZE`: 512 字节(数据记录的硬编码最大大小)
- `DEFAULT_VEC_SIZE`: 1048576 字节(1MB)用于向量存储
- `DEFAULT_RECORD_SIZE`: 与U8_DATA_MAX_SIZE相同(512字节)
- `DEFAULT_SELECT_SIZE`: 10 记录用于默认SELECT操作
- `FIELD_SIZE`: 8 字节(Long/Double字段的大小)

## 限制

- 复杂架构可能需要大量维护工作
- 对全局状态的严重依赖可能使测试复杂化
- 广泛使用不安全代码需要仔细审查

## 使用模式

该库设计用于以下实时流处理场景：
- 需要高吞吐量
- 基于SQL的转换是有益的
- 低延迟处理是关键的
- 内存效率很重要

## 集成点

- 通过`def_mapper`和`def_aggregate`的自定义回调函数
- 通过`FfiFunc`trait的FFI支持
- 通过TOML文件的配置
- 通过回调机制与其他系统的集成
